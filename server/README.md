# Game Server

## Visual Studio 프로젝트 만들기

Visual Studio에서 "Windows 콘솔 애플리케이션" 프로젝트를 새로 만든 뒤, `server` 폴더 안의 `main.cpp`와 `game_server.cpp`를 프로젝트에 추가한다. 프로젝트 속성 → 링커 → 입력 → 추가 종속성에 `ws2_32.lib`를 추가해야 Winsock 함수를 링크할 수 있다. 전처리기 정의나 추가 포함 디렉터리 설정은 필요 없다.

## 실행 결과

빌드 후 실행하면 다음 두 줄이 순서대로 출력된다.

```
[Init] 서버 준비 완료 — TCP/UDP 포트 9000
서버 대기 중. 종료하려면 엔터
```

엔터를 누르면 프로세스가 종료된다.

## 포트 충돌 시 메시지

9000번 포트를 다른 프로세스가 이미 사용 중이면 TCP bind 단계에서 실패하며 아래와 같이 출력된다(WSA 오류 코드 10048은 WSAEADDRINUSE).

```
[Init] TCP bind 실패 (포트 9000): 10048
```
